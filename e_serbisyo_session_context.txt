3. ARCHITECTURAL & UI CHANGES IMPLEMENTED
--------------------------------------------------------------------
- Routing Refactor: The monolithic `StaffDashboard.jsx` was deleted. It was split into two separate, single-responsibility pages: `StaffPendingReview.jsx` and `StaffReadyToPrint.jsx`.
- UI Stabilization (The "Jump" Fix): Implemented `overflowY: 'scroll'` on all main wrapper divs to lock the browser scrollbar in place, preventing the 15px horizontal shift when switching between long and short pages.
- Sidebar Standardization: Enforced a strict 280px width, 30px/25px padding, and identical flex layouts for the sidebars across all 4 Staff pages.
- Real-Time RBAC Sync: Added a 5-second interval `useEffect` on all Staff pages that silently pings the backend (`/api/staff/profile`) to check if the Admin has revoked the `canReview` permission, instantly kicking the user out of protected queues if access is revoked.
- Notification System: Added animated CSS (`pulse-red`) red notification dots to the sidebar to track active queues for `Pending` and `Ready to Print`.
